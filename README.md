# 👻 Just Climb

Juego 2D de plataformas con temática de horror, desarrollado en Python con
Pygame para el proyecto individual de la materia Software Factory II.

## Descripción

En Just Climb, el jugador comienza en el piso 0 y debe subir lo más alto posible.
Durante el recorrido debe saltar entre plataformas, esquivar monstruos y evitar
objetos peligrosos.

También puede recolectar frascos para aumentar su puntaje y conseguir power-ups
que le otorgan ventajas temporales.

La partida termina cuando el jugador pierde sus 3 vidas o cuando cae de las
plataformas. Al finalizar, el puntaje se guarda en una base de datos SQLite y se
muestra el ranking con los 5 mejores resultados.

## Cómo jugar

1. Ejecutar el juego.
2. Seleccionar la opción **Jugar** en la pantalla de inicio.
3. Usar la flecha izquierda para moverse hacia la izquierda.
4. Usar la flecha derecha para moverse hacia la derecha.
5. Presionar la barra espaciadora para saltar.
6. Esquivar los monstruos y los objetos peligrosos.
7. Recolectar los frascos para sumar puntos.
8. Conseguir power-ups para obtener ventajas temporales.
9. Subir la mayor cantidad de pisos posible.
10. Al perder todas las vidas o caer, consultar el puntaje final y el ranking.

## Controles

| Acción | Tecla |
|---|---|
| Moverse hacia la izquierda | Flecha izquierda |
| Moverse hacia la derecha | Flecha derecha |
| Saltar | Barra espaciadora |
| Seleccionar una opción | Enter |
| Salir del juego | Escape |
